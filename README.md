# claim-relay

**AI가 틀려도, 틀린 결과가 고객에게 그대로 나가지 않는 보험 청구 에이전트**

자동차사고 청구 한 건을 단계 에이전트 6개가 이어 받습니다. AI는 진술을 읽기만 하고, 과실 도표와 심사 경로는 공개 기준을 옮긴 규칙표가 정합니다. AI가 틀리면 어느 단계에서 왜 사람에게 넘어갔는지가 기록으로 남습니다.

### ▶ [담당자 화면 바로 보기](https://jhheo51-arch.github.io/claim-relay/web/#N009) (설치 없이 브라우저에서 열림)

[![담당자 화면](docs/img/screen-natural.png)](https://jhheo51-arch.github.io/claim-relay/web/#N009)

## 숫자 세 개 (가상 사고, 2026-10-28)

| | |
|---|---|
| **0건** | 사람이 봐야 할 사고를 자동 처리 후보로 넘긴 건(템플릿 46건, 말투를 바꾼 10건, 블라인드 20건 모두) |
| **6/20 대 18/20** | 다른 모델이 쓴 진술 20건의 심사 경로 일치. 낱말 규칙만 쓰면 6건, AI 추출을 붙이면 18건. 틀린 2건도 사람 심사로 감 |
| **초급 대 중급** | 같은 과실 에이전트도 추출기에 따라 등급이 갈림. 어느 단계를 고칠지 성적표가 짚어 줌 |

## 세 가지 장치

1. **사원증**: 에이전트마다 읽고 쓸 수 있는 칸이 정해져 있습니다. 범위를 넘거나 이미 쓴 칸을 고치려 하면 실행이 멈춥니다.
2. **인용 확인**: AI가 진술에서 뽑은 값마다 원문 인용을 남기고, 코드가 그 줄에서 인용을 다시 찾습니다. 못 찾으면 값을 버리고 사람 심사로 넘깁니다.
3. **성적표**: 단계마다 초급, 중급, 고급을 매깁니다. 등급이 그 단계 결과를 어디까지 믿고 쓸지를 정합니다.

처리 뒤에도 봅니다. 담당자 판정(`review`)을 남기면 파이프라인 결과와 맞춰 보고, 안내 뒤 고객이 다시 보낸 말(`followup`)에서 과실 이의나 민원 신호가 나오면 그 건을 다시 엽니다. 화면의 사고 탭에서 다시 온 말을 넣어 볼 수 있고, 운영 현황 탭에서 데이터 세트별 처리 경로와 멈춘 사고를 한눈에 봅니다.

단계는 ① 접수 ② 서류 점검 ③ 과실 도표 ④ 심사 경로 ⑤ 경상환자 8주 일정 ⑥ 고객 안내문 순입니다. 과실과 지급은 "예상", "확인 후 안내"로만 씁니다.

## 실제 업무에 붙인다면

- **개인정보**: 진술에 주민등록번호나 전화번호 꼴이 보이면 접수 에이전트가 AI에 넘기기 전에 실행을 멈춥니다(C039, C040). 실제로 붙이려면 이 검사를 가리기(마스킹) 단계로 바꾸고, AI에는 가린 진술만 보내야 합니다.
- **사람이 확인하는 지점**: 규칙 R01부터 R09 가운데 하나라도 걸리면 사람 심사나 서류 보완으로 보냅니다. 성적표 기준표에서 초급인 단계는 참고용으로 정해 두었지만, 지금은 파이프라인이 실행 중에 등급을 읽지 않습니다. 붙인다면 초급 단계가 낸 결과는 자동 처리 후보로 보내지 못하게 막는 일이 먼저입니다. 고객 안내문은 화면에 만들기만 하고 보내지 않으므로, 담당자가 확인한 뒤 내보내는 초안으로 씁니다.
- **잴 지표**: 사람이 볼 건을 자동으로 넘긴 건, 자동 처리 뒤 다시 열린 비율(재문의), 담당자 판정과 다른 비율, 처리 시간입니다. 앞의 셋은 담당자 화면의 **운영 현황** 탭에서 바로 봅니다. 처리 시간은 아직 재지 않습니다. 이력에 실행 시각 하나만 남기기 때문에, 단계별 시각을 남기는 일이 먼저입니다.

## 정직하게 적은 한계

- 사고, 고객, 견적 기준은 모두 가상입니다.
- 말투를 바꾼 10건에서는 10/10이었지만 진술과 정답을 같은 AI가 써서 후했습니다. 그래서 진술, 정답, 추출을 서로 나눠 다시 잰 [블라인드 20건](docs/BLIND.md)의 18/20을 대표값으로 씁니다. 그래도 사람이 쓴 진술은 아닙니다.
- Claude API를 직접 부르는 추출기(`--extractor api`)는 가짜 응답으로만 시험했고, 실제 호출은 아직 돌리지 않았습니다.
- 과실 도표 8개는 [과실비율정보포털](https://accident.knia.or.kr/ranking)에서 2026-10-28에 옮겼습니다.
