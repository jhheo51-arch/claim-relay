# claim-relay

**AI가 틀려도, 틀린 결과가 고객에게 그대로 나가지 않는 보험 청구 에이전트**

자동차사고 청구 한 건을 단계 에이전트 6개가 이어 받습니다. AI는 진술을 읽기만 하고, 과실 도표와 심사 경로는 공개 기준을 옮긴 규칙표가 정합니다. AI가 틀리면 어느 단계에서 왜 사람에게 넘어갔는지가 기록으로 남습니다.

### ▶ [담당자 화면 바로 보기](https://jhheo51-arch.github.io/claim-relay/web/#N009) (설치 없이 브라우저에서 열림)

[![담당자 화면](docs/img/screen-natural.png)](https://jhheo51-arch.github.io/claim-relay/web/#N009)

## 숫자 세 개 (가상 사고, 2026-10-28)

| | |
|---|---|
| **0건** | 사람이 봐야 할 사고를 자동 처리 후보로 넘긴 건(템플릿 사고 40건, 말투를 바꾼 10건 모두) |
| **3/10 대 10/10** | 말투를 바꾼 진술 10건의 심사 경로 일치. 낱말 규칙만 쓰면 3건, AI 추출을 붙이면 10건 |
| **초급 대 고급** | 같은 과실 에이전트도 추출기에 따라 등급이 갈림. 어느 단계를 고칠지 성적표가 짚어 줌 |

## 세 가지 장치

1. **사원증**: 에이전트마다 읽고 쓸 수 있는 칸이 정해져 있습니다. 범위를 넘거나 이미 쓴 칸을 고치려 하면 실행이 멈춥니다.
2. **인용 확인**: AI가 진술에서 뽑은 값마다 원문 인용을 남기고, 코드가 그 줄에서 인용을 다시 찾습니다. 못 찾으면 값을 버리고 사람 심사로 넘깁니다.
3. **성적표**: 단계마다 초급, 중급, 고급을 매깁니다. 등급이 그 단계 결과를 어디까지 믿고 쓸지를 정합니다.

단계는 ① 접수 ② 서류 점검 ③ 과실 도표 ④ 심사 경로 ⑤ 경상환자 8주 일정 ⑥ 고객 안내문 순입니다. 과실과 지급은 "예상", "확인 후 안내"로만 씁니다.

## 정직하게 적은 한계

- 사고, 고객, 견적 기준은 모두 가상입니다.
- 말투를 바꾼 10건은 진술과 정답을 AI가 썼습니다. 10/10은 실제보다 후할 수 있습니다.
- 과실 도표 8개는 [과실비율정보포털](https://accident.knia.or.kr/ranking)에서 2026-10-28에 옮겼습니다.
